## 1. 快速开始

命令行工具说明见 [命令行指南.md](命令行指南.md)。库集成最小示例见 [库集成.md](库集成.md)。

### 1.1 安装库

```bash
# Windows
mkdir build && cd build
cmake .. -DCMAKE_INSTALL_PREFIX="C:/Program Files/emvparse"
cmake --build . --config Release
cmake --install . --config Release

# Linux/macOS
mkdir build && cd build
cmake .. -DCMAKE_INSTALL_PREFIX=/usr/local
cmake --build . -j$(nproc)
sudo cmake --install .
```

### 1.2 在项目中使用

CMake 链接、`find_package` / `add_subdirectory` 与最小可编译示例见 **[库集成.md](库集成.md)**。

## 2. 系统要求

- **C++ 标准**: C++11 或更高版本
- **CMake**: 3.10 或更高版本
- **编译器**: 支持 C++11 的编译器（GCC 5+, Clang 3.5+, MSVC 2015+）
- **依赖项**: nlohmann/json（自动管理，无需手动安装）

### 平台支持

- ✅ Windows (MSVC, MinGW)
- ✅ Linux
- ✅ macOS

## 3. 编译和安装

### 3.1 方式一：开发/测试（仅编译，不安装）

**适用场景**：本地开发、运行测试、快速验证

#### 使用 vcpkg（推荐）

```bash
# Windows
mkdir build && cd build
cmake .. -DCMAKE_TOOLCHAIN_FILE="C:\Program Files\vcpkg\scripts\buildsystems\vcpkg.cmake" -DVCPKG_MANIFEST_MODE=ON -DVCPKG_TARGET_TRIPLET=x64-windows
cmake --build . --config Release

# Linux/macOS
mkdir build && cd build
cmake .. -DCMAKE_TOOLCHAIN_FILE=[vcpkg root]/scripts/buildsystems/vcpkg.cmake -DVCPKG_MANIFEST_MODE=ON -DVCPKG_TARGET_TRIPLET=x64-linux
cmake --build . -j$(nproc)

# 运行测试
ctest --output-on-failure
```

如果项目根目录有 vcpkg.json，CMake 配置时会自动安装依赖：
**说明**：这种方式只编译库，不安装到系统。编译结果在 `build/lib/` 和 `build/bin/` 目录中，适合开发和测试使用。

#### 不使用 vcpkg（CMake 自动下载依赖）

```bash
mkdir build && cd build
cmake ..
cmake --build . --config Release  # Windows
# 或
cmake --build . -j$(nproc)  # Linux/macOS

# 运行测试
ctest --output-on-failure
```

### 3.2 方式二：安装到系统（供第三方项目使用）

**适用场景**：生产环境、第三方项目集成

#### 使用 vcpkg（推荐，与方式一保持一致）

```bash
# Windows
mkdir build && cd build
cmake .. \
    -DCMAKE_TOOLCHAIN_FILE="C:\Program Files\vcpkg\scripts\buildsystems\vcpkg.cmake" \
    -DVCPKG_MANIFEST_MODE=ON \
    -DVCPKG_TARGET_TRIPLET=x64-windows \
    -DCMAKE_INSTALL_PREFIX="C:/Program Files/emvparse"
cmake --build . --config Release
cmake --install . --config Release

# Linux/macOS
mkdir build && cd build
cmake .. \
    -DCMAKE_TOOLCHAIN_FILE=[vcpkg root]/scripts/buildsystems/vcpkg.cmake \
    -DVCPKG_MANIFEST_MODE=ON \
    -DVCPKG_TARGET_TRIPLET=x64-linux \
    -DCMAKE_INSTALL_PREFIX=/usr/local
cmake --build . -j$(nproc)
sudo cmake --install .
```

#### 不使用 vcpkg（CMake 自动下载依赖）

```bash
# Windows
mkdir build && cd build
cmake .. -DCMAKE_INSTALL_PREFIX="C:/Program Files/emvparse"
cmake --build . --config Release
cmake --install . --config Release

# Linux/macOS
mkdir build && cd build
cmake .. -DCMAKE_INSTALL_PREFIX=/usr/local
cmake --build . -j$(nproc)
sudo cmake --install .
```

**说明**：
- **使用 vcpkg**：依赖管理更规范，适合生产环境，确保依赖版本一致
- **不使用 vcpkg**：CMake 会自动通过 FetchContent 下载依赖，但需要网络连接
- 安装后第三方项目可以通过 `find_package(EmvParse REQUIRED)` 使用

### 3.3 编译选项

```bash
# 禁用测试
cmake .. -DBUILD_TESTING=OFF

# 指定构建类型
cmake .. -DCMAKE_BUILD_TYPE=Release  # 或 Debug
```

## 4. API 参考

### 4.1 TLVParser 类

#### 构造函数

```cpp
TLVParser();                                    // 默认构造函数
TLVParser(const std::string& manifestPath, const std::string& scheme);  // 加载 Tag 规则
```

#### 主要方法

```cpp
// 加载 Tag 规则库
bool loadTagRegistry(const std::string& manifestPath, const std::string& scheme);

// 解析字节流（自动处理嵌套 TLV）
std::vector<std::shared_ptr<TLV>> parseBytes(const std::vector<uint8_t>& data);

// 解析 Hex 字符串（自动处理嵌套 TLV）
std::vector<std::shared_ptr<TLV>> parseHex(const std::string& hexStr);

// 解析为 JSON（包含语义信息）
std::string parseBytesToJson(const std::vector<uint8_t>& data);
std::string parseHexToJson(const std::string& hexStr);

// 查询 Tag 信息（从已加载的规则库中）
std::string getTagInfo(const std::string& tagHex) const;

// 设置日志回调函数
void setLogCallback(LogCallback callback);
```

**方法说明**：
- `setLogCallback(callback)`：设置日志回调函数，用于接收库产生的日志信息
  - **参数**：`callback` - 日志回调函数，类型为 `LogCallback`（`std::function<void(LogLevel level, const std::string& message)>`）
  - **日志级别**：`LogLevel::INFO`（信息）、`LogLevel::WARNING`（警告）、`LogLevel::ERROR`（错误）
  - **使用场景**：适用于需要将库的日志信息集成到自己的日志系统（如 Qt 的输出窗口）中的场景
  - **默认行为**：如果不设置回调函数，日志信息会输出到 `std::cerr`
- `getTagInfo(tagHex)`：查询指定 Tag 的元数据信息
  - **参数**：`tagHex` - Tag 的十六进制字符串（如 `"9F33"`）
  - **返回值**：JSON 字符串，包含 `name`、`description`、`template`、`type`、`format`、`length`、`kernel`、`source`、`note` 等信息；如果未找到该 Tag 或未加载规则库，则返回空字符串
  - **注意**：需要先调用 `loadTagRegistry()` 加载 Tag 规则库才能查询

**嵌套 TLV 解析**：根据 EMV 标准，通过检查 Tag 第一个字节的 **bit 6（构造位）**自动判断是否为复合标签：
- **bit 6 = 1**：复合标签，自动递归解析 Value 中的子 TLV
- **bit 6 = 0**：基本标签，Value 是原始数据

### 4.2 TLV 类

```cpp
// 数据访问
const ByteArray& getTag() const;
const ByteArray& getValue() const;
const Children& getChildren() const;  // 嵌套的子 TLV

// 工具方法
std::string tagHex() const;          // Tag 的十六进制字符串
std::string valueHex() const;        // Value 的十六进制字符串
std::string lengthHex() const;       // Length 的十六进制字符串（0xXX 格式）
```

## 5. 使用示例

### 5.1 基本使用

```cpp
#include <emvparse/tlv_parser.h>
#include <iostream>

int main() {
    TLVParser parser;
    auto tlvList = parser.parseHex("9F33020141");
    
    for (const auto& tlv : tlvList) {
        std::cout << "Tag: " << tlv->tagHex() << std::endl;
        std::cout << "Value: " << tlv->valueHex() << std::endl;
    }
    return 0;
}
```

### 5.2 解析嵌套 TLV

```cpp
TLVParser parser;
auto tlvList = parser.parseHex("6F0495020141");  // 复合标签

for (const auto& tlv : tlvList) {
    const auto& children = tlv->getChildren();
    for (const auto& child : children) {
        std::cout << "Child Tag: " << child->tagHex() << std::endl;
    }
}
```

### 5.3 使用 Tag 规则进行语义解析

```cpp
TLVParser parser("registry/manifest.json", "EMV");
std::string json = parser.parseHexToJson("95058000000000");
std::cout << json << std::endl;
```

### 5.4 查询 Tag 信息

```cpp
TLVParser parser("registry/manifest.json", "EMV");
std::string tagInfo = parser.getTagInfo("9F33");
if (!tagInfo.empty()) {
    std::cout << "Tag 9F33 信息：" << std::endl;
    std::cout << tagInfo << std::endl;
}
// 输出示例：
// {
//   "tag": "9F33",
//   "name": "Terminal Country Code",
//   "description": "终端国家代码",
//   "type": "NUMERIC",
//   "format": "BCD",
//   "length": "2",
//   ...
// }
```

### 5.5 解析字节流

```cpp
std::vector<uint8_t> data = {0x9F, 0x33, 0x02, 0x01, 0x41};
auto tlvList = parser.parseBytes(data);
```

### 5.6 设置日志回调（Qt 应用示例）

许多设计良好的库（如 OpenSSL、GLib）提供了设置日志回调函数的接口。本库也支持日志回调，允许你将库产生的日志信息发送到自己的输出窗口。

**Qt 应用示例**：

```cpp
#include <emvparse/tlv_parser.h>
#include <QDebug>
#include <QString>

// 定义日志回调函数
void myLogCallback(LogLevel level, const std::string& message) {
    QString qMessage = QString::fromStdString(message);
    
    switch (level) {
        case LogLevel::ERROR:
            qCritical() << "[TLV-Lib ERROR]" << qMessage;
            break;
        case LogLevel::WARNING:
            qWarning() << "[TLV-Lib WARNING]" << qMessage;
            break;
        case LogLevel::INFO:
            qDebug() << "[TLV-Lib INFO]" << qMessage;
            break;
    }
}

int main() {
    TLVParser parser;
    
    // 设置日志回调
    parser.setLogCallback(myLogCallback);
    
    // 加载 Tag 规则文件（此时日志会通过回调函数输出）
    bool loaded = parser.loadTagRegistry("registry/manifest.json", "EMV");
    if (!loaded) {
        qCritical() << "Failed to load tag registry";
        return 1;
    }
    
    // 解析 TLV 数据
    auto tlvList = parser.parseHex("95058000000000");
    
    return 0;
}
```

**C++ 标准库示例**：

```cpp
#include <emvparse/tlv_parser.h>
#include <iostream>
#include <fstream>

// 将日志写入文件
void fileLogCallback(LogLevel level, const std::string& message) {
    std::ofstream logFile("tlv_lib.log", std::ios::app);
    if (logFile.is_open()) {
        const char* levelStr = (level == LogLevel::ERROR) ? "ERROR" :
                               (level == LogLevel::WARNING) ? "WARNING" : "INFO";
        logFile << "[" << levelStr << "] " << message << std::endl;
    }
}

int main() {
    TLVParser parser;
    parser.setLogCallback(fileLogCallback);
    
    // 使用库...
    parser.loadTagRegistry("registry/manifest.json", "EMV");
    
    return 0;
}
```

**禁用日志回调**：

```cpp
// 传入 nullptr 或空函数对象，恢复默认的 std::cerr 输出
parser.setLogCallback(nullptr);
```

集成示例见 [库集成.md](库集成.md) 与上文 §5；Tag 规则数据见 `registry/`；解析与语义用例见 `test/test_tlv_parser.cpp`、`test/test_tlv_semantics.cpp`。

## 7. 常见问题

### 7.1 Tag 规则（manifest + 分层 JSON）

通过 `registry/manifest.json` 指定 `base`（`emv.json`）与各 scheme 的 overlay（如 `visa.json`、`upi.json`），调用：

```cpp
parser.loadTagRegistry("registry/manifest.json", "Visa");
```

字段契约与歧义处理见 [标签注册表数据模型.md](标签注册表数据模型.md) 与 [`tag-registry.schema.json`](../../registry/tag-registry.schema.json)。

### 7.2 依赖问题

如果找不到 `nlohmann/json`：
- 使用 vcpkg：`vcpkg install nlohmann-json`
- 或让 CMake 自动下载（需要网络连接）
