# emvparse 库集成（5 分钟）

## 已安装包（推荐）

```cmake
cmake_minimum_required(VERSION 3.10)
project(my_emv_app LANGUAGES CXX)

find_package(EmvParse REQUIRED)
find_package(nlohmann_json CONFIG REQUIRED)

add_executable(my_emv_app main.cpp)
target_link_libraries(my_emv_app PRIVATE EmvParse::EmvParse nlohmann_json::nlohmann_json)
target_compile_features(my_emv_app PRIVATE cxx_std_14)
```

配置前缀（非标准安装路径时必填）：

```bash
# Linux/macOS
cmake -B build -DCMAKE_PREFIX_PATH=/path/to/emvparse/install

# Windows（路径含空格请加引号）
cmake -B build -DCMAKE_PREFIX_PATH="C:/Program Files/emvparse"
```

仍找不到包时，可设 `-DEmvParse_DIR=".../lib/cmake/EmvParse"`（指向含 `EmvParseConfig.cmake` 的目录）。

`cmake --install` 后，`include/emvparse/` 下会安装四个头文件；**应用代码只需直接 `#include` 其中三个**（见下表）。`emvparse_global.h` 为 ABI 配套，由公开头自动带入，请勿在工程中单独包含。

## 源码树（add_subdirectory）

```cmake
add_subdirectory(path/to/emvparse)
target_link_libraries(my_emv_app PRIVATE EmvParse::EmvParse)
```

构建 emvparse 时默认 `-DBUILD_EMVPARSE_CLI=ON`、`-DBUILD_TESTING=ON`。

## 最小示例

```cpp
#include <emvparse/input_parser.h>
#include <iostream>

int main() {
    EmvInputParser parser("share/emvparse/tag-registry/manifest.json", "EMV");
    std::cout << parser.parseHexToJson("9F33020141") << std::endl;
    return 0;
}
```

将 `manifest.json` 路径换为你的安装路径或开发树中的 `registry/manifest.json`。

## Registry 校验 / 合并

不属于 install 头文件集。请使用 CLI `emvparse registry …`，或在源码树中为 target 增加 `src/tlv` 私有 include 后 `#include "tag_registry_ops.h"`（与 in-tree CLI 相同）。

## 头文件布局（install）

| 头文件 | 用途 |
|--------|------|
| `emvparse/input_parser.h` | `EmvInputParser` |
| `emvparse/output_options.h` | `ParseOutputOptions`、输出格式 |
| `emvparse/logging.h` | `LogLevel`、`LogCallback`（可选） |
| `emvparse/emvparse_global.h` | `EMVPARSE_EXPORT`（ABI 配套，勿直接 include） |

`src/` 下其余头（如 `tlv_parser.h`、`tag_registry_ops.h`）不随 install 发布。

完整 API、示例与编译选项见 [使用指南.md](使用指南.md)（§4 API、§5 示例）；Registry 模型见 [标签注册表数据模型.md](标签注册表数据模型.md)。英文：[user-guide.md](../en/user-guide.md)。
